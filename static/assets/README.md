# Bundled Backgrounds

These preview backgrounds are bundled for the local, offline touchpad surface.
They were downloaded from Unsplash image CDN URLs and are used under the
Unsplash License. They are decorative backgrounds only, not application data.

- `wallpaper_mountain.jpg`: <https://images.unsplash.com/photo-1469474968028-56623f02e42e>
- `wallpaper_night.jpg`: <https://images.unsplash.com/photo-1519608487953-e999c86e7455>
- `wallpaper_canyon.jpg`: <https://images.unsplash.com/photo-1500530855697-b586d89ba3ee>
- `wallpaper_anime.jpg`: <https://images.unsplash.com/photo-1578632767115-351597cf2477>

Users can replace or remove these files for a private build. The web client
also accepts a local image through its background picker and stores it only in
the browser's local storage.
